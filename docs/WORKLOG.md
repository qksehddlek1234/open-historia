# Cowork 세션 작업 로그

Cowork(클라우드) 세션이 배치마다 남기는 기록. 클로드 코드 세션은 여기서
"미커밋 변경의 출처와 의도"와 **파일에 흔적이 없는 라이브 데이터 힐**을
읽는다. 최신 항목이 위. 각 항목: 무엇을/왜/어느 파일/라이브 힐 여부.
