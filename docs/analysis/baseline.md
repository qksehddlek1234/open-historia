## 결과 요약

### ① 턴 진행 안정성 — 통과

10턴 전체 **오류 0건**. 모든 AI 호출(총 16회+) HTTP 200, 재시도·스키마 실패로 인한 멈춤 없음. 콘솔 에러 없음.

### ② 스키마 통과율 근사 — 실패 0/10턴

qwen3:14b + 32k 컨텍스트 조건에서 이벤트 생성 JSON이 한 번도 깨지지 않았다. (계획 단계에서 우려한 "14B가 스키마를 자주 깨뜨린다"는 이 설정에서는 미발생 — num_ctx를 32k로 키운 효과가 컸을 것으로 추정)

### ③ 턴당 소요 시간

- 사용자가 체감한 "너무 느림"은 **한국어 전환 직후의 UI 사전 번역 패스(총 4,387 문자열, 분당 ~124개 처리)가 게임 호출과 Ollama를 놓고 경쟁**한 영향이 가장 컸던 것으로 판단. 번역 캐시 완료 후에는 위 수치가 실제 체감치.

### ④ 이벤트 텍스트 품질

좋은 점: 자연스러운 한국어 원어 생성(후번역 아님), 문맥 일관성 우수 — 북한 미사일 시험 → 유엔 제재 논의 → 중국 반대 → 중·러가 외교 채팅으로 먼저 접촉해오는 흐름이 서로 연결됨.

발견된 문제:

1. **이벤트 반복**: 연속 두 턴에 거의 동일한 이벤트 생성 — "북한, 동해상 추가 미사일 시험 발사" → "북한, 동해 상공 추가 미사일 시험" (본문도 유엔/중국 반대 구조 동일). 기존 eventDedup이 유사-비동일 문장을 못 거름.
2. **한자 혼입**: "유엔 안理会는" — qwen 계열 특유의 중국어 토큰 누출이 한국어 출력에 섞임.
3. 이벤트 볼륨이 주당 0~1개로 다소 빈약 (원본 대비 밀도 비교는 Phase 1 캡처 후 판단).

### ⑤ 고문·외교 채팅 품질

- **외교 채팅 (중국)**: 응답 13~33초. 제재 반대 입장 유지, 6자회담 제안에 "북한의 협상 의지 평가 필수 + 비핵화 전제" — 국가 페르소나가 살아 있는 수준급 답변.
- **고문**: 응답 ~40초. 상황 평가 + 우선순위 3가지(중국 협력 / 군사 준비 / 반도체·AI 자립) + 결론의 구조화된 조언. 게임 상태(THAAD, 유엔 결의 실패)를 정확히 반영. 표현이 가끔 어색한 정도("미·일·러 연합" 등).
- **버그성 발견**: 자국(대한민국)과의 채팅 창은 메시지를 보내도 응답이 오지 않음(50초 대기, 호출 없음). 고문은 별도 패널(🧭 나침반 아이콘)에 있음 — 자국 채팅의 용도가 뭔지 확인 필요.

1. **속도 병목은 이벤트 생성이 아니라 "리소스 경쟁"이었다** → 역할별 모델 분리의 1순위 목표를 "translate·chat을 경량 모델(qwen3:8b)로 격리"로 확정. 번역 같은 대량 배치 작업이 Heavy 모델을 점유하지 못하게.
