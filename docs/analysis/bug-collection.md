## 요약 — 우선 조치 3건

1. **연속성 프롬프트 이식** (버그 5 대응): 원본도 못 막는 대체역사 붕괴를 프리셋 규칙 수준(연속성·환각 금지)으로 방어 — 수집한 프리셋 규칙을 기본 프롬프트에 반영.
2. **전이 검증 로그** (버그 1·4 대응): 점프 후 "이벤트가 언급한 지역 vs 실제 전이된 지역" 대조 결과를 콘솔/파일로 남겨 누락을 가시화.
3. **저장 원자성** (버그 8 대응): 턴 결과 다중 파일 쓰기를 원자적으로.
