## ⑦ 바다 영토화 (완료, 빌드 필요)

원본의 Sea Region처럼 바다가 소유·이전 가능한 지역이 되도록 구현:

- **데이터**: Natural Earth 해양 폴리곤 → `public/data/sea-regions.json` (118개 명명된 대양·바다·만·해협, 111KB, 퍼블릭 도메인).
- **켜는 법**: 치트 → **Sea Regions** → "Enable sea territories" (게임별 적용/해제 가능, 해제 시 바다 소유권 기록도 정리).
- **동작**: 바다도 클릭·양도(치트 Annex Regions, AI regionTransfers)·지역 카탈로그 등재(AI가 이름으로 인지) 전부 지역과 동일. 무소유 바다는 투명(경계선만), 소유되면 소유국 색 반투명 틴트.
- 권장 규칙 한 줄(치트 안내문에도 표시됨): `Sea regions represent naval control: transfer them only through naval victories, blockades, or treaties.`
- 지구본이 아닌 지구 지도 기반 게임용(판타지 맵에는 넣지 말 것).

- 배치: 군대 패널 → 보병 "Test Brigade" 배치 → 지도에 반투명(pending) 유닛 생성 + "배치 요청" 명령이 행동 큐에 자동 등록.

**원본과의 구조 차이**:

| | 원본 Pax Historia | Open-Historia |
|---|---|---|
| 군대 표현 | 일반 맵 피처(아이콘+이름). 전투력은 이름에 "(15/20)" 표기 — 프리셋 **규칙**이 시킴 | 전용 유닛 시스템(타입 6종, 전투력 수치, 상태), 지도에 원형+글리프+전투력 렌더 |
| 전투 | AI 서사가 전부 | 즉석 전투 판정기 + AI가 다음 턴에 전선 정합(명령 큐 방식) |
| 이동 제한 | 없음(서사) | 시대·병과별 이동 리시(초과 시 장거리 명령으로 AI가 수 턴에 걸쳐 진행) |

결론: 우리 쪽이 **원본의 상위 호환**이고 이미 지도에 통합돼 있어 엔진 수정은 불필요. 원본의 "(15/20)" 느낌은 규칙 세트 C(스타터 문서)의 부대명 표기 규칙을 붙여넣으면 AI가 원본과 동일하게 재현함. 이게 원본이 실제로 쓰는 방식(엔진이 아니라 규칙)임.
